# Pawns-Only Chess (Kotlin)

Консольная игра «шахматы пешками» на Kotlin. Два игрока ходят по очереди, доступны все стандартные ходы **пешек** (включая "съедание"), без превращения. Победа — когда пешка достигает последней горизонтали соперника или когда у соперника закончились пешки. Ничья — **пат** (у текущего игрока нет допустимых ходов). На каждом ходу доступно **интерактивное меню** легальных ходов: игрок выбирает номер.

---

## Возможности
- Текстовая доска 8×8 в монопространстве.
- Два игрока: White / Black.
- Обычные ходы пешек, **двойной шаг**, **взятие**, **взятие на проходе**.
- Выигрыш по достижению «финишной» линии или уничтожению всех пешек соперника.
- **Пат** при отсутствии ходов.
- Ввод через меню: `1`, `2`, … или `exit` для выхода.

---

## Требования
- **JDK 8+** (рекомендуется 17).
- **Kotlin CLI** (`kotlinc`, `kotlin`) для сборки из консоли.
- Терминал.

## Структура проекта

```
src/
└─ chess/
   ├─ app/
   │  └─ Main.kt          # точка входа, игровая петля, меню ходов
   ├─ core/
   │  └─ Board.kt         # модель доски и базовые операции
   ├─ model/
   │  └─ Model.kt         # Color, Player, Position, Piece (интерфейс), Pawn, Move, EnPassant
   ├─ rules/
   │  ├─ Generators.kt    # интерфейсы и реализации генераторов ходов (стратегии)
   │  └─ Rules.kt         # правила: генерация & применение хода, проверки выигрыша/пата
   └─ util/
      └─ Notation.kt      # форматирование клеток/ходов (e2e4)
```

## Сборка и запуск (вручную, без Gradle)

Из корня проекта:

```bash
kotlinc src -include-runtime -d pawns.jar
java -jar pawns.jar
```

## Сборка и запуск (Gradle, опционально)


## Как играть

1. Запусти приложение.
2. На экране появится доска и список легальных ходов текущего игрока.
3. Введи номер хода и нажми Enter.
4. Для выхода — введи `exit`.

Пример (фрагмент):
```
 Pawns-Only Chess
  +---+---+---+---+---+---+---+---+
8 |   |   |   |   |   |   |   |   |
  +---+---+---+---+---+---+---+---+
7 | B | B | B | B | B | B | B | B |
  +---+---+---+---+---+---+---+---+
...
White to move — выберите номер хода (или 'exit' для выхода):
1. a2a3
2. a2a4
3. b2b3
4. b2b4
...
Ваш выбор:
```

> Звёздочка `*` в списке помечает ходы, которые приводят пешку на последнюю горизонталь соперника (потенциальная победа).

## Архитектура

- **Интерфейс `Piece`** — базовый тип фигур (легко расширить под классику).
- **`Pawn`** — реализация пешки.
- **`Board`** — хранит фигуры, перемещение/снятие, печать доски.
- **Паттерн *Strategy*:** `AnyMoveGenerator` и конкретные генераторы (`PawnMoveGenerator`).
- **`Rules`** — движок правил: хранит `enPassant`, регистрирует генераторы и использует их для
  генерации, проверяет и применяет ходы (включая EP).
